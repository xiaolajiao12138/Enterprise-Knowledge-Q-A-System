# 企业信息安全与数据保密管理规范

## 第一章 账户与密码安全管理

1. **强密码策略**：所有办公系统、统一认证平台（SSO）、代码仓库和云控制台密码必须满足以下复杂度要求：
   - 长度不少于 12 位字符；
   - 包含大写字母、小写字母、数字及特殊符号（如 !@#$%^&*）；
   - 密码有效期最长为 90 天，到期系统强制提示修改，且最近 3 次使用过的历史密码不得重复使用。
2. **多因子认证（MFA）**：所有包含客户隐私数据、财务信息或核心生产环境的管理平台必须开启手机动态令牌（TOTP）或企业微信扫码二次认证。
3. **账户借用禁令**：员工账号仅限本人使用，严禁转借他人或与同事共享。离开办公工位时必须执行锁屏（快捷键 Win + L 或 Mac Control + Command + Q）。

## 第二章 数据分级与外传合规

1. **数据密级分类**：
   - **公开级（L1）**：对外发布的宣传材料、官网招聘信息；
   - **内部级（L2）**：公司内部通知、通用流程制度、内部培训资料；
   - **秘密级（L3）**：未公开财务报表、产品核心架构源码、重要客户商务合同；
   - **机密级（L4）**：核心商业机密、战略并购规划、用户高敏感隐私数据。
2. **代码与文档外传限制**：
   - 严禁将公司内部任何源代码、配置文件、数据库备份文件上传至 GitHub 公开仓库、Gitee、百度网盘或任何第三方公网存储；
   - 严禁将包含客户个人信息（身份证、手机号、银行卡）的数据发送至非公司域名的外部个人邮箱。

## 第三章 知识库与本地 AI 使用准则

1. **私有化 RAG 平台使用原则**：本企业内部知识库平台已部署在公司受控内网，上传知识库的所有文档严禁包含机密级（L4）的核心用户敏感隐私或未解密的财务核心凭证。
2. **大模型选型规范**：
   - 涉及企业内部 L2、L3 级文档的问答推理，必须使用企业本地私有化部署的大模型（如本地 Ollama 驱动的开源模型），严禁将内部敏感片段发送给未签订企业级数据保密协议的公网消费级大模型；
   - 知识库系统检索引用的文档片段只在内网流转，禁止截屏转发至外部社交软件。
